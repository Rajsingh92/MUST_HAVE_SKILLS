## Summary: 4-Month Timeline

| Month | Weeks | Focus |
|-------|-------|-------|
| **Month 1** | 1–4 | Arrays, Binary Search, Two Pointers, Strings, Sliding Window, Hashing |
| **Month 2** | 5–9 | Linked Lists, Stacks, Queues, Heaps, Hash-Based Structures |
| **Month 3** | 10–14 | Binary Trees, BST, N-ary Trees, Graph Traversal, Advanced Graphs |
| **Month 4** | 15–18 | Backtracking, DP (1D → 2D → Knapsack → Interval), Greedy |

---

**Key Principles for the Progression:**

1. **Month 1** builds intuition with arrays/strings — the most interview-common topics, using patterns like two pointers and sliding window that recur everywhere
2. **Month 2** covers all linear structures together so the stack→queue→heap relationship is clear
3. **Month 3** covers non-linear structures — trees before graphs since trees are a special case of graphs
4. **Month 4** covers algorithm design paradigms — backtracking before DP (DP = optimized backtracking), greedy last as it requires intuition built from DP
